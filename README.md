# Jason Lim — portfolio

A responsive, futuristic portfolio for software, data engineering, and applied AI projects. Plain HTML, CSS, JavaScript, and original SVG illustrations; no build step, containers, backend, API keys, or package installation required.

## Preview locally

From this directory, run `python -m http.server 4173 --bind 127.0.0.1`, then open `http://127.0.0.1:4173`.

## Publish with GitHub Pages

The intended repository is `jasonjlcl/jasonjlcl.github.io`. In repository **Settings → Pages**, choose **GitHub Actions** as the source. The included workflow publishes pushes to `main`. The intended public address is `https://jasonjlcl.github.io/`.

## Edit the content

- `index.html`: identity, introduction, project cards, about section, contact links, and metadata.
- `script.js`: project summaries, filtering, mobile navigation, and motion enhancements.
- `styles.css`: layout, colors, typography, responsive breakpoints, and reduced-motion support.
- `assets/`: locally served illustrations, favicon, and social preview image.

Contact currently links to the verified public GitHub profile. No email address, employment history, qualifications, testimonials, or availability claims have been invented.

The site uses local system font stacks, no analytics, and no external runtime libraries. Project links remain usable without JavaScript; filters and project dialogs are progressive enhancements. Motion respects the operating system's reduced-motion preference.
